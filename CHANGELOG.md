# Changelog

## 0.1.0 — 2026-10-05

Initial runnable research release.

- Built a Python/FastAPI engine and React/TypeScript radar with live WebSocket updates.
- Added five synthetic scenarios, clearance/readback lifecycle, missed-turn and altitude monitoring.
- Added interval-based traffic checks and synthetic weather-volume intersection.
- Added human request/takeover, data freshness handling, and explicit restoration of assistance.
- Added SQLite event history and JSON session export.
- Added geometry, engine, API and browser tests, a GitHub Actions workflow, and setup scripts.
- Documented source assumptions, hazard analysis, limits, and a beginner learning path.

No operational integrations, model inference, or voice transmission are included.
